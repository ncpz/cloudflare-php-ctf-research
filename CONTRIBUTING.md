# Contributing

This repository is a research record, not a maintained tool — but corrections, clarifications, and fixes to the documentation or scripts are welcome.

- **Corrections**: open an issue describing the error, ideally with the measured evidence. Factual claims in the writeup (offsets, sizes, counts, changelog quotations) were established by measurement; a correction should say what was measured differently and how.
- **Pull requests**: keep them small and scoped — typo/fix/doc improvements are merged freely. Please do not add new payload-generation content, live-target artifacts, or captures; the payload binaries are deliberately excluded (recipes in the README regenerate them).
- **Scope**: issues about the Cloudflare CTF itself, its rules, or the bounty program belong with Cloudflare (HackerOne / their blog), not here.
